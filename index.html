Game Rules

How to play?
A secret word is displayed with blanks for each letter. Guess a letter. If it's correct, it fills in the blank; if wrong, a part of the hangman is drawn. Each wrong guess adds to the hangman

Win or Lose:
Win: Guess the word before the hangman is fully drawn. Lose: The hangman is completed before the word is guessed.
